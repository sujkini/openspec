# Bug: CM-763

**Link:** https://issues.redhat.com/browse/CM-763

**Summary:** Operator logs show infinite Update operations after enabling multiple user-defined network policies

**Symptom:** With `defaultNetworkPolicy: true` and multiple `networkPolicies[]` entries, operator logs `NetworkPolicyUpdated` every ~400–800ms for same 4 policies over 1+ hour.

**Root cause:** User-defined NP reconciler performed unconditional updates even when spec unchanged — continuous reconcile loop.

**Fix PR:** https://github.com/openshift/cert-manager-operator/pull/339 (CM-763: Fix unconditional update)

**Type:** non_functional — performance / API server load
