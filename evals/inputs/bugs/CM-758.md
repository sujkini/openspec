# Bug: CM-758

**Link:** https://issues.redhat.com/browse/CM-758

**Summary:** Modify static-resources-controller managed NetworkPolicy Spec won't trigger a reconciliation

**Symptom:** After enabling `defaultNetworkPolicy: true`, manually patching a static NP (e.g. change API server egress port 6443→8089) is not reverted after 10+ minutes.

**Root cause:** Static NP controller (library-go) did not reconcile spec drift until library-go enhanced `ApplyNetworkPolicy` with proper watch/update semantics.

**Fix PR:** https://github.com/openshift/cert-manager-operator/pull/338 (CM-758: Bump library-go@release-4.20)

**Type:** functional — reconcile/watch gap on static-managed resources
