# Bug: CM-735

**Link:** https://issues.redhat.com/browse/CM-735

**Summary:** [Istio-csr] CR object intermittently not proceeded after creation: empty status and missing deployment

**Symptom:** IstioCSR CR created but `.status` empty, deployment not created. Operator log: `istiocsr.openshift.operator.io object not found, skipping reconciliation` despite reconcile triggered for `istio-system/default`.

**Root cause:** Race condition — istiocsr controller used separate cache from unified manager; CR not visible in controller cache at first reconcile.

**Fix PR:** https://github.com/openshift/cert-manager-operator/pull/324 (CM-735: unified manager cache)

**Attachments:** REPRODUCED_RACE_CONDITION_ANALYSIS.md on ticket

**Type:** functional — controller-runtime cache / reconcile reliability
