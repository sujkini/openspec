# Bug: CM-521

**Link:** https://issues.redhat.com/browse/CM-521

**Summary:** [OSSM integration] Upstream bump for istio-csr v0.13.0+

**Symptom:** OSSM team integration testing found istio-csr version incompatible with OpenShift Service Mesh v3 / Istio v1.24+.

**Root cause:** Operand version in bindata/static manifests below minimum required for OSSM v3.

**Fix:** Bump static manifests in `bindata/istio-csr` with v0.13.0+ (later v0.14.2 via PR #304, v0.15.0 via PR #363).

**Fix PR:** https://github.com/openshift/cert-manager-operator/pull/304 (CM-675: Rebase v0.14.2)

**Type:** functional — version skew / integration
